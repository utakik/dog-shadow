# svg_html_puppet

HTML / SVG / MediaPipe Hands based dog puppet experiments.

## Folder rule

Each dated folder is one experiment stage.

The root of each experiment folder contains the representative files used by the prototype.

source/ contains original files, previous versions, screenshots, failed or unusable files, and hand-edited source materials.

## Experiments

- 260717_open_mouth
  - first HTML/SVG dog puppet prototype
  - similarity transform test
  - open mouth / fixed SVG attempt
  - fixed SVG was not suitable for intended layer control, so it is kept in source as unusable reference

- 260720_closed_mouth_layers
  - hand-edited closed mouth state
  - reorganized SVG layers
  - intended as next working base for CLOSED / OPEN-BARK / LICK mouth state control
