## 最終実装

- 塗りを毛で表現する新しい分岐。従来の `live_rig.html` とは別名で開発。
- 毛は鼻筋・額・頬・耳・下顎・顎下・後頭部ごとに長さ、方向、密度、太さを調整できる。
- 毛は手の移動速度に反応し、静止中にも低周波のランダムな揺れを加える。
- 刺繍はスケッチの方向を参考に、鼻は渦状、目は接線・放射状、舌と牙は長手方向、耳内側は横方向に配置。
- 刺繍色はリグの元色を使用。微細な蠢きと移動時の反射を追加。初期設定の動きは刺繍より毛を大きくする。
- 近距離で手が大きく映ると本数を増やし、刺繍糸を短くする。
- 20cm付近の刺繍密度を50cm付近でも得たいという要望に合わせ、密度基準を170から110へ変更。ただし実距離は測定せず、映像中の手首〜中指付け根の長さで推定するため、50cmは目安。
- 額・頬・鼻筋・後頭部の角度と長さ等を連続補間し、スケッチで指摘された分け目を緩和。
- 口の変形で長く飛び出す刺繍線に対し、中心を個別に結び付け、基準長の1.12倍を上限としてから長さ補正を適用。
